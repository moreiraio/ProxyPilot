What it does

Everything on the wire, and nothing invented.

Bodies are stored exactly as they arrived. Everything that makes them readable happens at display time, so what you inspect and what crossed the wire never drift apart.

HTTPS decrypted on your terms

CONNECT is relayed blind by default. Turn decryption on and it is intercepted instead, a certificate minted per host, and the requests inside listed individually — alongside the origin's real certificate, chain and validity.

  • Decryption and trusting the root are two separate decisions
  • The status bar says so out loud when the two disagree
  • The root is never installed without an explicit request

Bodies made readable, without touching the wire

Compression is undone, JSON and XML are reformatted, protobuf is read with no schema, forms are split into their fields and images are previewed — all of it at display time. The stored bytes stay exactly what arrived.

  • gzip, Brotli and Zstandard, decoded in-house
  • Stacked encodings unwound in the order they were applied
  • A row that was reformatted says so, so you are never guessing

Break it, rewrite it, answer it

Arm breakpoints and the next message stops here: edit the head, edit the body, forward it or drop it. AutoResponder rules answer a matching request without it ever leaving the machine.

  • Before the request goes out, after the response comes back
  • Narrow it to a host or a path
  • Fail open — a hold that times out forwards, and says it did

Craft a request, or replay a captured one

The composer sends by dialling ProxyPilot's own listener, so a replay is captured exactly like any other transaction — same rules, same decryption, same row in the list.

  • Edit the head line by line, or paste it raw
  • Replay any selected session
  • Content-Length follows whatever you type

Find it by asking for it

One field above the list narrows it live across host, path and process. Press Enter and the same query becomes a full-text search that decodes compressed bodies to look inside them.

  • status:5xx, host:api, method:POST, type:json
  • >100kb and <1mb for size
  • Every term ANDs with the rest

Event streams, decoded while they are still open

A text/event-stream response has its events framed and listed as they arrive — each with its offset from the start of the stream, its type and its size. WebSocket upgrades are decoded the same way, frame by frame.

  • No waiting for the stream to close
  • gRPC split into messages, and judged by grpc-status in the trailers
  • HTTP/2 spoken inside decrypted tunnels when its toggle is on too

Read what it cost

Statistics over the whole capture in one pass: totals, the result mix, latency percentiles, which hosts and which processes moved the bytes, and what compression actually saved.

  • Per-session timings break the dial into DNS, TCP and TLS
  • Caps and exclusions are stated, never silent
  • A waterfall view sits beside the overview
And the rest

The parts you only notice when they are missing.

Bodies

Decoded in-house

gzip, Brotli and Zstandard, stacked encodings unwound in order, JSON and XML pretty-printed, protobuf read with no schema, images previewed, form bodies split into fields.

Bypass

A hole that announces itself

A named host or process is carried as though ProxyPilot were not in the path — no row, no decryption, no rules. The status bar counts it, because an incomplete capture must never be quiet.

Remote

A phone, a tablet, the machine next door

Bind off loopback to named addresses only, gate it with a CIDR allowlist, and let the device browse to the proxy for a page that hands over the root certificate.

Browsers

Launched already wired up

Chrome, Edge, Brave, Firefox and their forks, started into a throwaway profile pointed at the proxy — so only that window is captured and your system proxy is never touched.

Scripting

JavaScript, with FiddlerScript's reach

onRequest and onResponse can rewrite bodies, read and write files, open sockets and run processes. Which is why it is off until you throw the switch, and loud on the status bar while it is on.

Export

Take it with you

HAR 1.2 in both directions, one session as its own HAR, copy as a cURL command or a Postman collection, and any response body saved to disk decoded and correctly named.

Network

A deliberately worse connection

A bandwidth cap and added latency from a status-bar preset, shared across every connection, so a slow link is something you can reproduce rather than describe.

Privacy

Nothing leaves this machine

No account, no telemetry, no update check, no network calls of its own. It works with no network connection at all.

Yours to drive

Three themes, including a contrast theme with its ratios pinned by a test. Twenty-two built-in columns plus eight of your own. Twenty-four rebindable shortcuts — and a chord another command already holds is refused by name, not by that key is in use.

Nothing dangerous is implied

Decryption, HTTP/2 and ignoring certificate errors are three switches, not one. Nothing seeds a default, nothing turns another thing on, and a consent dialog is never worked around.

Honest edges

What it does not do.

Most of these are decisions rather than gaps. They are here for the same reason the status bar counts the bypass list: a tool that quietly shows less than what happened is the failure this program is written against.

  • Windows only. x64, Windows 10 or later. No macOS, no Linux.
  • No HTTP/3. QUIC is UDP with its own congestion control and its own TLS integration, none of which Schannel exposes.
  • The capture is not persisted. It lives in a memory ring and is gone on exit. HAR export is how it leaves.
  • Columns do not sort. The list is in capture order, permanently — the filter grammar answers the same questions instead.
  • No regex in search. The prefixes cover what regex would be reached for, and they AND rather than OR.
  • No SAZ. HAR 1.2 goes both ways; Fiddler's own archive format does not.
  • No cloud, no team features, no account. There is nothing to sign in to.
  • Bounded, and it says so. Decoded bodies cap at 4 MB and formatted output at 8 MB; the bytes are still captured in full.
Get it

One file. Run it.

There is nothing to install and nothing to configure. Start it, point a client at 127.0.0.1:8888, and the rows appear.

ProxyPilot.exe

The program. 2.6 MB, x64. Settings land in a config.json beside it, so the whole thing travels as one folder.

Download v0.1.0

The root certificate comes with it

Nothing to download. The program mints its own root the first time you turn decryption on and writes it beside config.json as ProxyPilotRoot.cer and .pem. Trusting it is always a separate, explicit act.
